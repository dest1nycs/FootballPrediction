# FMPS - Football Match Prediction System

Desktop application for football match analysis and prediction.

## Features

- User registration
- User login
- Remember me
- Match prediction
- League standings
- User profile
- Statistics tracking
- Football-data API integration

## Technologies

- C#
- WPF
- .NET
- XAML
- JSON
- Football-data API
